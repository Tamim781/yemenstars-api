# مساعد نجوم اليمن للمأكولات البحرية

هذه النسخة تستخدم **Gemini فعلياً في كل رسالة**. أزيل منها المحرك القديم الذي كان يطابق كلمات مثل «فوائد» و«تتبع» ثم يرجع نصوصاً ثابتة. المسار الأساسي هو FastAPI في `main.py`، و`server.py` مجرد نقطة تشغيل توافقية تشغل المسار نفسه.

## ما يفعله المساعد
يفهم الرسالة وسياق الجلسة ثم ينشئ رداً جديداً عن المنيو، الأسعار، الوصف، المقارنة، طرق الطهي، الاقتراحات، المعلومات الغذائية العامة، الموقع، الساعات، التوصيل وطرق الدفع. يدعم العربية واللهجة اليمنية ولا يحول كل رسالة إلى اقتراح وجبة.

تم استبعاد مشاكل الطلبات، الشكاوى، التعويضات، الإلغاء والتعديل، التأخير، تتبع الطلب ومكان السائق من اختصاصه عمداً. عند السؤال عنها يوجّه العميل إلى شاشة الطلبات أو قناة المطعم الموجودة في الكتالوج، ولا يخمّن الحالة.

## التشغيل

```bash
pip install -r requirements.txt
cp .env.example .env
# ضع GEMINI_API_KEY الحقيقي في .env
uvicorn main:app --host 0.0.0.0 --port 8000
```

أو:

```bash
python server.py
```

## الربط من تطبيق الهاتف

أرسل:

```http
POST /api/chat
Content-Type: application/json
```

```json
{
  "message": "ما الفرق بين الديرك المشوي والجمبري البروست؟",
  "session_id": "sess_اختياري_من_الرد_السابق",
  "context": {"screen": "menu", "language": "ar"}
}
```

الاستجابة:

```json
{
  "answer": "...",
  "session_id": "sess_...",
  "status": "success"
}
```

احفظ `session_id` في التطبيق وأرسله في الرسائل التالية حتى يستمر الحوار. لا ترسل كلمات مرور أو رموز تحقق أو بيانات بطاقات في `message` أو `context`.

## الملفات المهمة

- `main.py`: API ونقطة المحادثة.
- `services/gemini_service.py`: استدعاء Gemini وبناء سجل الحوار.
- `prompts/customer_service.py`: البرومبت العالمي ونطاق المساعد.
- `knowledge/restaurant_catalog.json`: المنيو وبيانات المطعم التي يجب تحديثها عند تغيير الأسعار.
- `services/session_manager.py`: عزل جلسات العملاء والذاكرة المؤقتة.

## فحص سريع

```bash
curl http://localhost:8000/health
curl -X POST http://localhost:8000/api/chat \
  -H 'Content-Type: application/json' \
  -d '{"message":"السلام عليكم، ما الذي تنصح به لشخصين؟"}'
```
